# Отчет по лабораторной работе №2

Цель работы
Развернуть систему мониторинга на базе Prometheus и Grafana, автоматизировав установку и настройку средствами Ansible.

Поставленные и выполненные задачи
В ходе работы требовалось решить несколько связанных задач, и все они выполнены:

подготовлена инфраструктура из трёх узлов — node1, node2 и mon;

написан Ansible playbook, автоматизирующий развёртывание;

установлены и настроены Nginx, Prometheus Node Exporter, Prometheus Server и Grafana;

импортирован готовый дашборд Node Exporter Full (ID 1860);

проверена идемпотентность playbook при повторном запуске.

Результаты выполнения
Повторный прогон playbook подтвердил, что изменения вносятся только там, где это необходимо:

text
понедельник : ok=19  changed=4  unreachable=0  failed=0
node1       : ok=3   changed=0  unreachable=0  failed=0
node2       : ok=3   changed=0  unreachable=0  failed=0
На основном узле (понедельник) потребовалось четыре изменения, на рабочих узлах (node1, node2) изменений не было — их состояние уже соответствовало описанному в playbook. Недоступных и сбойных узлов нет.

Вывод
Система мониторинга развёрнута и работает: Prometheus собирает метрики с узлов через Node Exporter, Grafana отображает их на импортированном дашборде. Идемпотентность подтверждена — повторный запуск не приводит к лишним изменениям.
