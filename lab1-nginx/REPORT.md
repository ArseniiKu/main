# Отчет по лабораторной работе №1

Цель работы
Автоматизировать установку и настройку Nginx на целевых узлах с помощью Ansible.

Поставленные и выполненные задачи
сформирован инвентарь хостов с целевыми узлами;

написан Ansible playbook для установки Nginx;

настроены роли, чтобы вынести установку и конфигурацию в переиспользуемые блоки;

проверена идемпотентность playbook при повторном запуске.

Результаты выполнения
Повторный прогон playbook показал, что состояние узлов уже соответствует описанному в ролях, поэтому изменений не потребовалось:

text
PLAY RECAP
node1 : ok=X  changed=0  unreachable=0  failed=0
node2 : ok=X  changed=0  unreachable=0  failed=0
На обоих узлах changed=0, недоступных и сбойных хостов нет — значит, повторный запуск не вносит лишних изменений.

Вывод
Nginx развёрнут на всех целевых узлах. Playbook идемпотентен: повторный запуск подтверждает соответствие состояния узлов описанной конфигурации и не приводит к повторным изменениям.
